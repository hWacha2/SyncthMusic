# Интерфейс

Интерфейс собирается заново, по одному экрану. Первый шаг — выбор папки с
музыкой. Пока в приложении нет навигации, плана синхронизации и остальных
разделов: они вернутся позже, уже на новой основе.

## Направление

- фон `#151517`, без градиентов и свечений;
- крупная антиква для вопроса, системный гротеск для действий, моногротеск для
  путей;
- один акцент — тёплый оранжевый, только на главном действии;
- асимметричная композиция: текст слева, пустота и тонкая окружность справа;
- на ПК системный диалог выбора папки, на Android — встроенный браузер папок,
  потому что SAF отдаёт URI, а ядру нужен обычный путь.
