# План работ

Версия 0.2 — **без встроенного плеера** (ADR-001). Продукт = движок синхронизации
библиотеки + тонкие приложения + интеграции с чужими плеерами.

Формат: фазы сдаются независимо, каждая заканчивается работающим артефактом.
Оценки — для одного разработчика.

---

## Что выкинуто из плана 0.1

| Выкинуто | Почему | Что вместо |
|---|---|---|
| Аудиодвижок, gapless, ReplayGain | AIMP/Poweramp уже это умеют | ничего |
| Фоновое воспроизведение, MediaSession, lockscreen | сложно и не наша ценность | ничего |
| «Продолжить на другом устройстве» | это фича плеера | отложено, возможно навсегда |
| Стриминг с ПК на Android | Poweramp не умеет HTTP | выборочная синхронизация; WebDAV для AIMP/foobar |
| Собственный экран «Сейчас играет» | — | — |

Ядро (скан, хеши, CRDT, транспорт, политики) не меняется — плеер был надстройкой.

## Phase 0 — Ядро (2–3 недели)

Никакого UI. `crates/core` + `crates/cli`.

- [ ] Cargo workspace, CI (fmt, clippy, nextest), AGPL-3.0
- [ ] Схема SQLite + миграции (WAL, FTS5)
- [ ] Сканер: обход, `size+mtime+file_id`, BLAKE3 (rayon), теги через `lofty`
- [ ] Chromaprint (`fpcalc`), фолбэк без него
- [ ] HLC, CBOR, подписи Ed25519, `apply()` + материализация
- [ ] Снапшоты и компакция
- [ ] LAN-транспорт: mDNS + QUIC + range-запросы
- [ ] `Pipe::Folder` (ops в директорию)
- [ ] Политики пинов: бюджет, правила, эвикция
- [ ] `pending.delete` + логика «файл исчез»
- [ ] CLI: `scan`, `status`, `pair`, `sync`, `serve`, `verify`, `doctor`

**Готово, когда:** две машины, общая папка ops, `syncth sync` → одинаковый
`state_hash`; файл переезжает по LAN; удаление файла на A вскрывается как
`pending.delete`, но ничего не удаляет на B без подтверждения.

**Бенчмарк сразу:** скан 100 ГБ FLAC (нужно ≥ 300 МБ/с на HDD, ≥ 1 ГБ/с на SSD).

## Порядок, который нельзя менять

1. **CLI раньше UI.** UI на нестабильном ядре съест втрое больше времени.
2. **Папка для ops раньше Iroh.** 100 строк кода доказывают корректность CRDT без
   сетевой отладки.
3. **Windows раньше Android.** Быстрее цикл, проще отладка, а «архивное» устройство
   всё равно ПК.
4. **Политики раньше дедупа.** Без выборочного хранения телефон бесполезен;
   дедуп — приятный бонус, который можно добавить позже без ломки модели.
5. **Никаких плагинов, пока нет стабильного API ядра.** Плагин к нестабильному
   ядру — это второй фронт поддержки.

## Критерии «не провалили проект»

- 10 000 треков / 1 ТБ: инкрементальный скан < 2 с, дельта ops < 100 КБ.
- Новое устройство получает метаданные библиотеки < 60 с.
- Ни одна операция не требует сервера.
- Пользователь ни разу не видит слов «хеш», «blob» и «CRDT».
- Пользователь не удалил ни одного файла случайно (проверяется на `pending.delete`).
- После синхронизации AIMP/Poweramp показывают ровно то, что ожидалось, без
  ручного «пересканировать библиотеку».
