# План работ

Версия 0.3 — **без плеера** (ADR-001), **библиотека = зеркало одной папки**
(ADR-002), **личное использование**, а не массовый продукт.

Следствие: iOS нет, стриминга нет, транскодинга нет, настройки раскладки нет.
Есть два устройства (телефон + ПК), одна папка, один честный синк.

---

## Что выкинуто и почему

| Выкинуто | Почему |
|---|---|
| Аудиодвижок, gapless, ReplayGain | AIMP/Poweramp уже это умеют |
| Фоновое аудио, MediaSession, lockscreen | не наша ценность, огромный объём |
| Стриминг с ПК на Android | Poweramp не умеет HTTP |
| Транскодинг | в модели «зеркало папки» файл либо есть, либо нет |
| Управляемая раскладка, шаблоны путей | пользователь сам разложил — не трогаем |
| iOS | без плеера и общего UI смысла нет |
| Аккаунты, подписки, релеи | личное использование, LAN + Tailscale |

телефона не ломает синхронизацию; за сутки батарея не проседает.

## Phase 3 — Вне дома (1 неделя или 0, если Tailscale)

Порядок предпочтения:

1. **Tailscale** (или любой WireGuard): оба устройства в одной сети, синк работает
   по IP. Ноль кода, ноль серверов, бесплатно для личного использования.
   **Рекомендуемый вариант.**
2. `iroh` + `iroh-blobs` — если хочется «поставил и работает» без сторонних
   приложений. 3–4 недели, публичные релеи/дискавери.
3. Nostr для store-and-forward манифеста — только если устройства никогда не
   бывают онлайн одновременно.

## Порядок, который нельзя менять

1. **CLI раньше UI.** UI на нестабильном ядре съест втрое больше времени.
2. **Windows раньше Android.** Быстрее цикл отладки; телефон всё равно
   тестируется против ПК.
3. **Синк раньше «умной музыки».** Дедуп и обложки ничего не стоят, если не
   работает базовая передача.
4. **Никаких плагинов, пока ядро не стабильно.**
5. **Ни одного молчаливого удаления.** Это единственное правило, нарушение
   которого стоит пользователю его фонотеки.

## Критерии «работает»

- 10 000 треков / 1 ТБ: инкрементальный скан < 2 с, дельта ops < 100 КБ.
- Новое устройство получает дерево и метаданные < 60 с.
- Перенос 50 ГБ по Wi-Fi идёт на скорости сети (≥ 40 МБ/с) и переживает обрыв.
- Переименование 500 альбомов не передаёт ни байта.
- Ни одна операция не требует сервера.
- Пользователь ни разу не видит слов «хеш», «blob» и «CRDT».
- После синка Poweramp и AIMP показывают ровно то, что ожидалось, без
  «пересканировать библиотеку» вручную.
