# Архив интерфейса до Vue

Здесь лежит исходный ванильный интерфейс SynctMusic: `index.html`, `app.css`,
`i18n.js`, `app.js`. Он сохранён как эталон поведения и внешнего вида, пока
новый интерфейс собирается в `../ui` на Vue.

Каталог не участвует в сборке приложения: `tauri.conf.json` смотрит на
`../ui/dist`.

## Посмотреть архив отдельно

Из этого каталога:

```powershell
python -m http.server 8123
```

Затем открыть `http://127.0.0.1:8123/`. Мост Tauri при этом недоступен, поэтому
приложение покажет экран «нет связи» — это ожидаемо.

## Временно вернуться на старый интерфейс

В `../src-tauri/tauri.conf.json` заменить:

```json
"frontendDist": "../ui/dist"
```

на:

```json
"frontendDist": "../ui-archive"
```

и убрать `beforeBuildCommand`.
