# SynctMusic

**Синхронизация музыкальной библиотеки, которая понимает музыку.**
Не сервер, не облако, не плеер. Слой между твоей папкой с музыкой и любимым плеером.

Один каталог на всех устройствах: ПК держит архив, телефон — только то, что нужно.
Плейлисты, обложки, оценки и удаления синхронизируются осознанно, а не как «файл
пропал — ну и ладно».

> Статус: **проектирование**. Документы: [архитектура](docs/architecture.md),
> [план](docs/roadmap.md).

## Зачем это, если есть Syncthing

Syncthing синхронизирует **файлы**. Музыкальная библиотека — это не файлы, а
сущности: трек, альбом, обложка, сторона винила, дубль в mp3, «удалить отсюда, но
не отовсюду».

| Задача | Syncthing | SynctMusic |
|---|---|---|
| Телефон получает только избранное | ignore-паттерны вручную, без учёта места | политики: бюджет, лайки, плейлисты, «следующий месяц» |
| Один трек в FLAC и MP3 — это дубль | два файла навсегда | дедуп по аудио-фингерпринту, апгрейд качества |
| «Удалил на телефоне» | удаляет на ПК | выбор: освободить место / убрать из библиотеки / вернуть |
| Обложки и буклеты | просто файлы, часто дубли | привязаны к альбому, канонический `cover.jpg` |
| Плейлисты | M3U с чужими путями | генерация M3U под пути каждого устройства |
| Новый файл сразу виден в плеере | плеер сканирует когда захочет | триггер media scan / индексации |
| Батарея на Android | постоянный скан | передача только по Wi-Fi/на зарядке, батчами |

## Ключевая идея

Библиотека — это **два независимых слоя**:

1. **Манифест** (килобайты): лог подписанных CRDT-операций. Реплицируется через
   любую «глупую трубу» — папку, WebDAV, публичный релей. Сервера нет.
2. **Блобы** (гигабайты): аудио и обложки, адресуемые по BLAKE3. Передаются
   напрямую между устройствами, только когда нужны, всегда с проверкой хеша.

Поэтому: устройствам не нужно быть онлайн одновременно, файлы не ходят через
облако, а «что хранить на телефоне» становится явной настройкой, а не фокусом с
ignore-паттернами.

## Чего в продукте осознанно нет

- **Встроенного плеера.** AIMP, foobar2000, MusicBee, Poweramp, USB Audio Player
  Pro уже лучше нас. Мы делаем так, чтобы они видели правильные файлы в нужном
  месте в нужное время.
- **Сервера и аккаунтов.** Идентичность — ключевая пара, пейринг — QR-код.
- **Стриминга из облака.** Только свои устройства. Опционально — «стриминг с ПК»
  через WebDAV для плееров, которые это умеют (AIMP, foobar2000).
- **Редактирования тегов по умолчанию.** Правка тегов мутирует файл; это отдельная
  явная операция, а не побочный эффект.

## Название

«SynctMusic» созвучно с торговой маркой Syncthing — перед публикацией стоит выбрать
нейтральное имя (*Loom*, *Crate*, *Tapehead*, *Vinyl*). Внутренние имена пакетов
уже нейтральны (`syncth-core`).
