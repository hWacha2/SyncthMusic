# SyncthMusic

**Локально-первичная (local-first) музыкальная библиотека: один каталог, много устройств, ноль серверов.**

SyncthMusic — это опенсорсный плеер и синхронизатор, который держит единую музыкальную
библиотеку на всех твоих устройствах, не пересылая сами файлы через облако и не требуя
арендованного сервера. Метаданные, плейлисты и состояние плеера реплицируются как CRDT;
аудиофайлы передаются напрямую между устройствами (LAN или P2P) по контентному адресу.

> Статус: **стадия проектирования**. Кода ещё нет. Документы: [архитектура](docs/architecture.md),
> [план](docs/roadmap.md).

## Проблема

Существующие решения заставляют выбирать:

| Подход | Пример | Проблема |
|---|---|---|
| Медиасервер | Navidrome, Jellyfin, Plex | Нужен постоянно включённый хост, место, трафик |
| Файловая синхронизация | Syncthing, Resilio | Нет модели библиотеки: нет плейлистов, счётчиков, «продолжить на другом устройстве», нет выборочного хранения |
| Проприетарные | Plexamp, Symfonium | Закрытый код, подписка/оплата |
| Облако | Spotify, Apple Music | Не твоя библиотека, не твои файлы, подписка |

Ниша: **библиотека как объект, а не папка**. Файлы — деталь реализации; пользователь
управляет треками, политиками хранения и плейлистами.

## Три инварианта

1. **Ноль обязательной инфраструктуры.** Проект не должен иметь ни одного сервера,
   без которого приложение не работает. Всё, что требует сети, — заменяемо
   (папка, WebDAV, публичный релей, собственный VPS пользователя).
2. **Файлы не ходят через облако.** Только напрямую, только между *своими*
   устройствами, всегда с проверкой BLAKE3.
3. **Никаких аккаунтов.** Идентичность — ключевая пара. Пейринг — QR-код.

## Что получается

```
        ┌──────────── ПК (2 ТБ) ────────────┐        ┌──── Телефон (128 ГБ) ────┐
        │  UI (Flutter)                     │        │  UI (Flutter)            │
        │  ─────────────────────────────    │        │  ─────────────────────   │
        │  core (Rust)                      │        │  core (Rust)             │
        │   scan → hash → index → CRDT      │        │   пины + очередь + плеер │
        │        │        │        │        │        │        │                 │
        │   library.db   ops.log   blobs    │        │   library.db  cache      │
        └────────┬────────────────┬─────────┘        └───────┬─────────────────┘
                 │                │                          │
      блобы (QUIC, BLAKE3)   ops (подписаны)      блобы (по требованию)
                 │                │                          │
                 └────────────────┴──────────────────────────┘
                                  │
                    «глупая труба» для манифеста:
              папка / WebDAV / Nostr-релей / git / S3
                    (переживает офлайн, стоит 0)
```

## Возможности (целевые)

- Единая библиотека на всех устройствах без сервера
- Умные политики хранения: телефон держит только нужное, остальное стримит с ПК
- Синхронизация плейлистов, лайков, счётчиков, позиции воспроизведения
- Дедупликация по аудио-фингерпринту (один трек с разными тегами ≠ два трека)
- Автоматический апгрейд качества (mp3 → FLAC, когда появляется лучшая копия)
- Плеер: gapless, ReplayGain, FLAC/Opus/MP3, без рекламы и подписок
- Транспорт на выбор: только LAN, P2P через интернет, или вообще «синхронизируй
  папку чем хочешь — Syncthing, Nextcloud, флешка»

## Лицензия

Планируется AGPL-3.0 (серверная часть отсутствует, но AGPL защищает от появления
закрытого облачного форка).

## Название

«SyncthMusic» созвучно с торговой маркой Syncthing. Перед публикацией стоит выбрать
нейтральное имя (варианты: *Loom*, *Crate*, *Tapehead*, *Vinyl*). Внутренние имена
пакетов уже нейтральны (`syncth-core`).
